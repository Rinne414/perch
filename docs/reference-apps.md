# 參考程式：借了什麼、避開了什麼

最後更新：2026-10-01。每一項都先問：它解決使用者哪個痛點？（拖延、忘了要做什麼、點子沒記下、忘了日期、忘了上次做是多久以前、agent 跑完忘了回去看。）

## 設計原則

1. 記下來不能有阻力　2. 做過的事不會消失（自動記時間，也能事後補記）　3. 只有需要你動手時才打擾你　4. 浮窗只顯示「現在」　5. 開始比做完重要（永遠給出下一步）　6. 誠實但溫和　7. 跳過不受罰　8. 好看也是功能　9. agent 是一等公民（公開的事件格式、每筆資料都有來源、可按來源清除；agent 建議，人決定）　10. 資料在本機、格式公開、可匯出　11. 電腦活動紀錄另外保護　12. 不開網路連接埠

功能分層：(1) 解決哪個痛點？(2) 打開時會不會多出要看或要處理的東西？(3) 沒在用的時候看得到嗎？三項都過 = 核心；只有 (2) 不過 = 選配、預設關；(3) 不過 = 交給 agent 或腳本；(1) 不過 = 不做。

優先順序由 Fable 子代理審過（2026-10-01）。

## 沒有借的（刻意不做）

- **連續天數、積分、成就**（習慣 App、Todoist Karma）：違反「跳過不受罰」。
- **「隨便幫我挑一件」按鈕**（Marvin）：浮窗的「下一步」本來就是那個答案；多一顆常駐按鈕違反「沒用時看不到」，也和第 18 項重疊。
- **開啟時跳出「你有 12 件逾期」**（TickTick）：只在有兩件以上時，在今天清單的尾端安靜地提供批次選項。
- **專注模式的統計和每日總計**：會讓「先做 5 分鐘」變成新的 KPI。每一次計時仍然記在時間軸上，給之後的回顧用。

## 已知限制

- 「看 1/2 章」裡的 1/2 會被讀成日期；輸入時的提示會顯示讀到的日期，看得到就能改。
- 一次只顯示一個「復原」提示；刪除後一分鐘內都還救得回來，但只有最後一個有按鈕。
- 「回去」的指令是給 PowerShell 或 POSIX shell 貼的；cmd.exe 不吃 `;`。
